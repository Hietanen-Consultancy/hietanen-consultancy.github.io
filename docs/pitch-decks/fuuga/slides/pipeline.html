Hietanen Consultancy · Fuuga · 04

The pipeline reads left to right. Provenance at step one is what a regulated buyer needs; the measurement at the end is what a technical buyer tests. Detail — Ingest: documents, Parquet and text become a hashed corpus, and every checkpoint records which sources trained it. — Transfer: donor weights from nine model families, mapped architecture-aware, or a small model pre-trained from scratch. — Fine-tune: LoRA and QLoRA on consumer GPUs, DPO for preferences, GRPO reinforcement learning with verifiable rewards. — Compress: distil, merge, prune and quantise to a bit budget; export GGUF for llama.cpp and Ollama, or ONNX. — Serve: OpenAI- and Anthropic-compatible APIs with continuous batching, guardrails, tool calling, MCP and A2A. — The whole pipeline is a typed CLI over a recipe file, which is why an agent can run it end to end. Built-in evaluation, drift detection and a typed judge say whether a run was a regression. Measurement, not compute, is the bottleneck in automated model development, and the typed judge is what closes the loop.
