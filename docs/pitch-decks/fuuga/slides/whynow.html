Four shifts and one gap in the market. Detail — Open models: Llama, Qwen, Gemma, Mistral, DeepSeek and Kimi publish weights that, adapted to a company's own cases, beat a generic hosted model at that company's tasks. Fuuga imports all of them. — Prices: hosted inference is priced below cost to win share, and the providers are funded by investors to do it. The largest provider reports losing more than it earns on the service, and analysts estimate API prices would need to rise several-fold to reach sustainable economics. Owning the model turns a per-request bill that will rise into a fixed cost on hardware the company already has. — Sovereignty: boards now ask where the model runs and what it was trained on. Provenance is built into every Fuuga checkpoint. — The .NET gap: the path Microsoft offers .NET teams today is GitHub Copilot, Microsoft 365 Copilot and Azure OpenAI — models made by OpenAI and Anthropic, run in Microsoft's cloud and rented per request. It is good at what it does, and none of it gives a company a model it owns, can retrain on its own outcomes, or can run inside its own network. — Hardware: QLoRA, offloading and NVMe paging mean a useful model is adapted on one workstation GPU, and quantised export runs it on CPU servers the customer already owns. — Shapes: typed decision engines for software to consume, rather than prose for a person to read, arrived this year with serious money behind them. More shapes will follow, which is the argument for owning the platform rather than betting on one of them.
