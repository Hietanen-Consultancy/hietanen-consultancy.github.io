Hietanen Consultancy · Fuuga · 05 · Source: Fuuga README, September 2026

Everything listed is in the repository today, and a live walkthrough of the code is available as a follow-up. Detail — Training: BPE tokenizer, transformer with RoPE, GQA, MLA and MoE; AdamW and Muon; gradient checkpointing, CPU and NVMe offload for models larger than VRAM. — Fine-tuning: SFT, prompt tuning, DPO, GRPO reinforcement learning, rejection sampling, LoRA and QLoRA, adapter merging, and a typed judge arena for old-versus-new comparisons. — Model operations: weight transfer from nine donor families, distillation, N-ary merging, pruning, NF4 and INT8 quantisation, GGUF and ONNX export, HuggingFace round-trip. — Serving: OpenAI- and Anthropic-compatible endpoints, both mounted by default, with streaming, function calling, structured outputs, continuous batching, bearer auth, guardrails, MCP and A2A. — Metered hosting: fuuga-serve --provider-config prices each model per token, keeps a prepaid credit ledger per API key and publishes the price list in OpenRouter's format. A customer or partner can run its own model as a paid service, sold per token, without building billing. — Agents: local minion delegation with sandboxed tools and skills, multi-model cost-aware orchestration, hybrid RAG with a knowledge graph. — Also shipped: Stable Diffusion 1.5 implemented from scratch, text-to-video and captioning, exposed as MCP tools; OpenTelemetry observability; bit-exact export round-trips.
