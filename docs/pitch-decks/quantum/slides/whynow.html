Why now

The rules already allow swarms. The software is what is missing.

One pilot, many aircraft, already lawful

An EASA operational authorisation records a remote-pilot-to-aircraft ratio — 1:5, or a pool of three pilots to ten aircraft. The cap comes from the automation the aircraft's flight manual documents, not from a rule still to be written.

Deployment, not legislation, is the bottleneck

UK BVLOS flies today in atypical air environments — rail, power-line and wind-farm corridors — under a handful of authorisations. Five years after the EU's U-space regulation, one U-space airspace is live.

Quantum hardware is on the cloud

Azure Quantum sells IonQ, Quantinuum, Rigetti and Atom Computing time by the job; D-Wave annealers handle thousands of variables; Microsoft is building the Majorana machine we already simulate.

AI agents need a typed API

Coding agents can write a builder expression; they cannot invent a QUBO encoding. A high-level, typed library is how quantum reaches the code that agents will write.

So the developer layer arrives before the fleets — which is the only time it can be built, and the reason the buyer today is the vendor shipping the fleet software rather than the operator flying it. The revenue does not wait for quantum: what a customer buys is fleet planning that works now on classical hardware, with the quantum path wired behind the same API.
